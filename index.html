Welcome to HTML Learning

HTML is the first step toward becoming a web developer. Learn how websites are created and how information is displayed on the internet.

1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create web pages. HTML provides the basic structure of a website and organizes its content.

With HTML, we can add headings, paragraphs, images, links, lists and tables to a webpage.

Note: HTML is a markup language, not a programming language.

2. History of HTML

HTML was created by Tim Berners-Lee in 1991. It was developed to help people share information through the World Wide Web.

Over the years, HTML has improved with new features. HTML5 introduced better support for images, audio, video and modern website structures.

3. Importance of HTML

HTML is important in web development because:

Website Structure

It organizes the content of web pages.

Easy to Learn

Its simple tags make it beginner-friendly.

Browser Support

It works in all major web browsers.

4. Basic Structure of HTML

Every HTML document follows a basic structure. Here is a simple example: 

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to HTML.</p>
</body>
</html>

Explanation:

  • <html> Defines the HTML document.
  • <head> Contains page information.
  • <title> Sets the page title.
  • <body> Contains visible content.

5. Common HTML Tags

HTML uses different tags to display different types of content.

  • <h1> - Main heading.
  • <p> - Paragraph.
  • <br> - Line break.
  • <a> - Creates a link.
  • <img> - Displays an image.
  • <ul> - Creates a bullet list.
  • <table> - Creates a table.
  • <div> - Creates a content container.

6. HTML Elements and Attributes

An HTML element usually consists of an opening tag, content and a closing tag. 

<p>This is a paragraph.</p>

Attributes provide extra information about HTML elements. 

<a href="https://www.google.com">
    Visit Google
</a>

Here, href is an attribute that specifies the destination of the link.

8. Difference Between HTML and CSS

HTML and CSS are both important technologies used to create websites.

HTML

HTML creates the structure of a webpage, such as headings, paragraphs and images.

CSS

CSS controls the appearance of a webpage, including colors, fonts and layouts.

9. Advantages of HTML

  • Easy to learn and understand.
  • Free to use.
  • Supported by all major browsers.
  • Helps create the structure of websites.
  • Can be used with CSS and JavaScript.
  • Supports images, audio and video.

10. Conclusion

HTML is the foundation of web development. It helps us create and organize website content. Learning HTML is an important first step for anyone interested in creating websites.

Remember: HTML creates the structure, while CSS makes the website attractive.
